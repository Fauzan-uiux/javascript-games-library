# 🎮 JavaScript Game Library Manager

A beginner-friendly JavaScript project built to practice and demonstrate core JavaScript programming concepts through a simple video game library management system.

## 📌 About the Project

This project allows users to manage a collection of video games using JavaScript.

It demonstrates how fundamental JavaScript concepts can be combined to organize, search, filter, and manipulate data.

## ✨ Features

- Display all games in the library
- Search for a game by name
- Add new games to the library
- Prevent duplicate game entries
- Filter games by price
- Display game names
- Calculate the total library value
- Check which games are installed
- Remove the last game from the library

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Run index.js using Node.js:

```bash
node index.js
```

Alternatively, paste the code into an online JavaScript compiler.
